# B9M Manager

Jeu de gestion de handball dans le navigateur : tu prends en main un club fictif, tu règles ta tactique et tu vis un championnat de 16 clubs simulé possession par possession.

**Jouer :** https://adx-codes.github.io/b9m-manager/

## Développer

```bash
python3 build.py        # assemble src/ en index.html
node --check src/engine.js src/ui.js
```

- `src/` : code source (moteur, interface, gabarit)
- `docs/game-design.md` : document de game design
- `CLAUDE.md` : instructions de travail pour Claude
